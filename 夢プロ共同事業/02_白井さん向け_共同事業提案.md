## 1. ご提案の要点

白井さんの人脈と発想を、アチーバーが**販売し、継続運営できる仕組み**にします。

最初は大きく始めません。**ホテル1施設・1商品・90日**で、売れるか、測れるか、続けられるかを確かめます。

## 2. 現状と問題

- 白井さんには、企業・ホテルとの関係、鈴木優香さんとの接点、夢プロの構想があります。
- 一方で、企画を「商品」にし、価格を決め、提案・契約し、発信を回し、成果を数字で報告する仕事は、誰かが継続して担う必要があります。
- ここが決まらないと、話題になっても1回で終わり、関係者に利益が残りません。

## 4. 役割

| | 担うこと |
|---|---|
| **白井さん（クレド）** | ホテル・企業との関係づくり、施設との調整、スパの提供と運営、出演者への打診の窓口 |

| **アチーバー** | 商品設計、営業、提案・見積、契約調整、進行管理、販売導線、採算管理、継続営業 |
| **アチーバーのAIチーム** | 施設調査、提案書の下書き、動画の切り出し補助、投稿文案、紹介ページ文案、問い合わせ回答案、成果集計 |

選考・交渉・公開内容の確認・契約判断は、人が行います。AIチームは作業の下書きと集計を担当し、狙いは**販売開始までの日数と制作・運営の工数を減らすこと**です。ただし処理能力はまだ実証前のため、今回の採算では時間短縮を見込まずに計算しています。

## 5. 収益の考え方（仮定）

| | 内容 | 金額（仮定） |
|---|---|---|
| 協賛（主力） | 体験協賛／特典協賛（商品提供付き） | 1社50万円／20万円 |
| 施設：企画運営費 | 初期一括 | 30万円 |
| 施設：月額運営料 | 3か月 | 10万円×3 |
| 施設：成果報酬 | 利用完了1件あたり | 6,000円 |
| 個別案件費 | 追加動画など | 1件15万円 |

当初は、施設から企画運営費80万円＋月額25万円×3をいただく案でした。この場合、**ホテルは識別予約20件で約90万円の赤字（損益分岐は約45件）**となり、施設が受け入れにくいと判断しました。初回だけ出演費・撮影費が重くかかるためです。

そこで、**協賛企業を収益の主力**にして出演費・撮影費を賄い、施設には固定費を抑えた上で成果報酬を加える形に組み替えました（詳細は次章「アチーバー収益設計」）。協賛が2社未満だとアチーバーは赤字になるため、協賛の内諾を着手の条件にします。

クレドの収益（スパ施術料のほか、協賛を紹介いただいた場合の紹介料）は、ご意見をいただいて決めたい事項です。

## 6. 最初の90日

| 期間 | やること | 判断 |
|---|---|---|
| 1〜14日 | 施設選定・提案、出演の打診、計測方法の合意、契約 | 14日目：着手可否 |
| 15〜35日 | 商品設計、撮影、短尺動画、紹介ページ、予約システムへの専用プラン設定 | |
| 36〜80日 | 発信・販売、週次集計、改善 | 45日目：中間確認 |
| 81〜90日 | 成果報告、継続判断 | 90日目：継続可否 |

**測るもの**　再生数、紹介ページ訪問、予約画面への遷移、識別できた予約完了、キャンセル、利用完了、施設の売上と増分利益、アチーバーの案件利益。

予約完了は専用リンクのクリックでは確認できないため、ホテルの予約システムに**専用プランコード**を作っていただき、プラン別の予約データ（個人情報なし）を月次でいただく形を基本にします。
