## 1. ご提案内容

貴施設の客室・お食事・スパを組み合わせた**90日間の限定プラン**を企画し、出演者の体験映像を使って発信し、**貴施設の公式予約システム**でご予約いただく導線を作ります。

予約・決済は貴施設の既存システムで行います。お客様の個人情報を当社が取得することはありません。

## 2. 当社が提供するもの

| 提供物 | 内容 |
|---|---|
| 商品設計 | プラン内容・価格案・利用条件案（最終決定は貴施設） |
| 撮影・動画 | 撮影1日、縦型短尺動画（例：6本）、静止画素材 |
| 紹介ページ | プラン紹介ページ1枚、公式予約画面への導線 |
| 発信運用 | 出演者投稿の調整、貴施設アカウント用の投稿文案、広告配信（予算は別途協議） |
| 問い合わせ対応補助 | よくある質問の整備、回答案の作成（回答は貴施設または当社担当者が確認） |
| 報告 | 週次の数値共有、月次報告、90日目の成果報告と改善案 |

## 3. 貴施設にお願いする協力事項

1. 予約システムでの**専用プラン（プランコード）**の設定
2. プラン別予約データの月次共有（個人情報を除く：予約番号または管理番号、予約日、宿泊日、室数・人数、金額、状態、予約経路）
3. 撮影日の客室・お食事・スパのご提供（撮影協力）
4. 公開前の内容確認（写真・料金・利用条件の表記）
5. 施設名・写真の使用範囲のご承認

## 4. 費用の内訳（仮定）

| 項目 | 金額（税抜・仮定） | 内容 |
|---|---|---|
| 企画運営費 | 800,000円 | 商品設計・撮影段取り・動画・紹介ページ・計測設計 |
| 月額運営料 | 250,000円×3か月 | 発信運用・問い合わせ補助・集計・報告 |
| 広告配信費 | 別途協議 | 実費。上限額を事前に合意 |
| 個別案件費 | 1件150,000円〜 | 追加動画・季節の差し替え等。ご依頼時のみ |

料金体系は、固定費を下げて利用完了1件ごとの成果報酬を組み合わせる形もご相談可能です（予約データの共有が前提）。

## 5. 予約の計測方法

| 段階 | 計測方法 | 計測する側 |
|---|---|---|
| 動画の再生 | 各SNSの管理画面の数値 | 当社 |
| 紹介ページ訪問 | ページのアクセス計測 | 当社 |
| 予約画面への遷移 | 「予約画面へ進む」ボタンのクリック計測 | 当社 |
| 予約完了 | 専用プランコードの予約一覧 | 貴施設 |
| キャンセル・利用完了 | 同上の状態区分 | 貴施設 |

クリック数だけでは予約は確定しないため、予約完了は貴施設のデータで確認します。予約番号で重複を除き、日程変更は同一予約として扱います。OTA経由など識別できない予約は、成果に含めず別に記録します。

## 6. ご報告する内容

週次：再生数、ページ訪問、予約画面への遷移、識別できた予約数
月次・90日目：上記に加え、キャンセル・利用完了、プラン売上（利用完了ベース）、変動費を差し引いた限界利益、既存のお客様の振替を考慮した増分利益の試算、改善案

増分利益の算定方法（振替の見方）は、事前に貴施設と合意します。
