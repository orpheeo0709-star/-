# 90日間の実行計画（初回実証：ホテル1施設・1商品）

Day 0＝施設との契約日（未定）。日程は仮置き。

| 週 | 主な作業 | 担当 | 成果物 | 判断・確認 |
|---|---|---|---|---|
| 準備（契約前） | 白井さんと方針合意、施設候補調査、提案 | アチーバー／クレド／AIチーム（調査・下書き） | 施設調査メモ、提案書 | 先行負担上限（工数込み30万円）の範囲内か |
| 1〜2週 | 契約、着手金、専用プランコード設定、出演条件の合意、計測方法の合意 | アチーバー／施設／クレド | 契約書、出演条件書、計測仕様 | **14日目 着手判断** |
| 3週 | 商品設計確定、撮影台本、許諾範囲の確認 | アチーバー／AIチーム（台本下書き） | プラン仕様、撮影台本 | 施設・出演者の確認 |
| 4週 | 撮影（1日） | アチーバー／外部撮影／出演者／施設／クレド（スパ） | 撮影素材 | |
| 5週 | 編集、紹介ページ、投稿文、FAQ | 外部編集／AIチーム（切り出し・文案）／アチーバー（確認） | 動画6本、ページ、投稿文 | 公開前確認（出演者・施設） |
| 6週 | 公開、計測開始 | アチーバー／出演者／施設 | 公開ページ | 計測が動いているか確認 |
| 7週 | 発信・広告、週次集計 | アチーバー／AIチーム（集計） | 週次報告 | **45日目 中間判断** |
| 8〜11週 | 改善（訴求・広告配分・FAQ）、協賛営業 | アチーバー／AIチーム | 改善版素材、協賛提案書 | |
| 12週 | 予約データ受領、集計、報告書作成 | 施設／AIチーム（集計）／アチーバー（確認） | 成果報告書 | |
| 13週 | 報告会、継続判断 | 全員 | 継続案または終了報告 | **90日目 継続判断** |

## 毎週測るもの
再生数、紹介ページ訪問、予約画面への遷移、識別できた予約（施設データ受領時）、問い合わせ件数、作業時間（人・AIチーム別）

作業時間を記録するのは、AIチームによる工数削減を推測ではなく実測で示すためです。
