# 応募前に説明すべき条件チェックリスト（下書き）

使い方：申込の受付前に、ルムッシュ側で**すべての「回答欄」を埋め**、あやママが承認する。空欄のものは「要確認」のまま、公開・案内をしない。
下の「推奨の説明方針」は引継ぎ指示の原則に基づく方針であり、具体的な金額・条件ではありません。

## 1. 企画の性質
| 項目 | 推奨の説明方針 | 回答欄 |
|---|---|---|
| 主催者・窓口 | ルムッシュの公式窓口。仲介者・協力者が条件交渉をしないこと | 要確認 |
| 採用につながる企画か | はい。ただし参加＝入店ではない | 方針確定済み |
| 参加費 | 有無・金額 | 要確認 |
| 対象 | 成人（20歳以上）の女性。年齢・居住地の条件 | 要確認 |
| 紹介制クラブとの関係 | 本企画は採用説明であり、来店募集ではない | 要確認 |

## 2. 仕事内容と仕組み
| 項目 | 推奨の説明方針 | 回答欄 |
|---|---|---|
| 仕事内容 | 具体的に（接客、同伴・アフター等の有無） | 要確認 |
| ヘルプから学ぶこと | 新人はヘルプから。卓の売上が本人の売上とは限らない | 方針確定済み |
| 係制度 | 係の経路は3つ（係の退店後の店客／オーナーママからの引継ぎ／本人の店外での新規開拓）。割当・収入は保証しない。「店客＝フリー・新規客」ではない | 方針確定済み（運用詳細は要確認） |
| 勤務 | 曜日・時間・最低出勤・遅刻欠勤の扱い | 要確認 |

## 3. お金
| 項目 | 推奨の説明方針 | 回答欄 |
|---|---|---|
| 報酬の仕組み | 時給／バック等の構成。**保証しない**。例示する場合は条件付きで根拠を明示 | 要確認 |
| 控除 | 控除される項目と金額・算定方法（衣装・ヘアメイク・送迎・罰金等の有無） | 要確認 |
| 交通・宿泊費 | 体験会はオンラインで不要。現場確認・短期滞在の負担者・上限・対象 | 要確認 |
| 支払い方法・時期 | | 要確認 |
| 税・社会保険の扱い | 契約形態による | 要確認（確認先） |

## 4. 本人の自由・安全
| 項目 | 推奨の説明方針 | 回答欄 |
|---|---|---|
| 顔出し・SNS発信 | 応募・参加の条件にしない。公開取材・写真掲載は別途本人の同意 | 方針確定済み |
| 退職・移住 | 条件にしない。地元で判断できる | 方針確定済み |
| 参加の中断・辞退 | いつでも可。不利益なし | 方針確定済み |
| 飲酒 | 強要しない。個人の判断（体質・年齢・体調） | 要確認 |
| ハラスメント・トラブルの相談先 | 担当者名・連絡先 | 要確認 |
| 身分証・年齢確認 | 必要な時期・目的・保管方法 | 要確認 |
| 副業・兼業の可否 | 現職の規則は本人が確認する旨 | 要確認 |

## 5. 個人情報
| 項目 | 推奨の説明方針 | 回答欄 |
|---|---|---|
| 取得項目 | 申込時は必要最小限（ニックネーム可、連絡手段、希望日程）。本名・住所・身分証は必要時に | 要確認 |
| 利用目的 | 体験会の運営・連絡のみ | 要確認 |
| 保管先・期間・削除 | 誰が保管し、いつ削除するか。削除請求の手順 | 要確認 |
| 第三者提供 | 協力者・協力先に提供しない | 方針確定済み |
| 録画・録音 | 同意がある場合のみ。用途・保管 | 要確認 |

## 6. 表現の確認（告知前）
- [ ] 「必ず売れる」「高収入」「稼げる」等の保証的表現がない
- [ ] 「業界初」「日本初」等の事実の主張がない
- [ ] 実績・数字・提携・効果は確認済みのもののみ
- [ ] オンラインで分かるのは会話の一面であり適性確定ではない、と記載
- [ ] 申込導線が公式窓口（協力者を経由した囲い込みなし）
- [ ] 未成年が対象外であることが明記されている
- [ ] 法的確認（広告表現・募集・個人情報）を実施または担当者が判断済み［確認先・要確認］
