# 参加・相談・面談・入店・定着の最小管理表（案）

システム開発はしません。既存の表計算（スプレッドシート）で足ります。運用負荷が大きいと分かった時点で、改めて必要性を判断します。
**本資料は様式のみで、実在の応募者情報は一切含みません。** 実データはルムッシュが管理し、アクセスできる人を最小限にしてください（取り扱いは `04` の個人情報欄の確定後）。

## シート1：候補者（1人1行）
| 列 | 内容 | 備考 |
|---|---|---|
| ID | 連番（P001…） | 氏名の代わりに集計で使う |
| 連絡名 | ニックネーム可 | 本名は必要時のみ |
| 流入経路 | 動画／SNS／協力者A／LINE／その他 | 協力者名は同意した範囲 |
| 申込日 | | |
| 参加日（体験会） | 空欄＝不参加 | |
| 模擬接客の参加 | 希望・実施・見学のみ | |
| フィードバック要点 | 良い点／伸ばす点（要約） | 容姿への言及は記録しない |
| 個別相談 | 希望なし／希望／実施（日付） | **本人の自発的希望か**を記録 |
| 現場確認 | なし／調整中／実施（日付） | |
| 面談 | なし／実施（日付） | |
| 入店日 | 空欄＝未入店 | |
| 入店後30日・60日・90日 | 継続／離脱／確認中 | 90日は入店日から別途追跡 |
| 離脱の段階と理由 | 申込後／体験後／相談後／面談後／入店後 + 理由（本人の言葉） | 責めない・追い込まない |
| 本人の納得度 | 5段階＋コメント（本人の自己申告） | |
| 連絡停止・削除の希望 | 有無・日付 | あれば即対応 |

## シート2：時間と費用
| 列 | 内容 |
|---|---|
| 日付 | |
| 担当者区分 | ママ／窓口／先輩／斎藤 |
| 作業内容 | 撮影／告知／受付／体験会／個別相談／面談／教育 など |

## シート3：週次サマリー（自動集計）
- 流入経路別：申込→参加→相談→面談→入店の件数。
- 担当者区分別の合計作業時間、現金支出の累計と上限との比較。
- 離脱理由の上位。

## シート4：定着の追跡（入店者が出てから）
| 項目 | 内容 |
|---|---|
| 指導担当・相談担当 | |
| 最初の30日の学習内容と実施 | |
| 先輩・相談担当の追加時間と追加報酬 | 費用に含める |
| 既存の係への影響 | |
| 本人の収入・適性・納得 | 保証しない。実績として記録 |

## 費用指標
- **90日定着者1人当たり費用 ＝ 採用関連総費用 ÷ 入店後90日継続者数**
- 採用関連総費用 ＝ 現金支出 ＋（作業時間×単価［単価・要確認］）。途中離脱者に使った費用も含める。
- 入店後90日の結果が出るまで確定させない。30日の運用では「暫定」と表示する。

## 運用ルール
- 本人以外が見てよい項目と、保管先・期間・削除の手順を決める（要確認）。
- 協力者には候補者の個別情報を共有しない（集計の件数のみ）。
- 質問・離脱の自由を尊重し、催促の連絡はしない。
