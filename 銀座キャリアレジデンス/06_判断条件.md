# 短期滞在支援へ進む判断条件／継続・修正・停止の判断案（下書き）

**数値の基準はすべて「要確認」です。** 根拠のない閾値を作らないため、30日の実績を見て、あやママと斎藤が事前に合意して決めます。以下は判断の観点と、基準を決めるための枠組みです。

## 1. 30日終了時の判断（体験室の結果）
| 観点 | 見る事実 | 基準 |
|---|---|---|
| 届いたか | 申込・参加の件数、経路別の内訳（動画／SNS／協力者） | 要確認 |
| 自分の意思で進んだか | 地元に住む女性が、誘導なしに個別相談を希望した件数 | 要確認 |
| 内容は合ったか | 本人の納得度、質問の内容、離脱理由 | 要確認 |
| 負担は妥当か | ママ・窓口・先輩の合計時間、現金支出（上限との差） | 要確認 |
| 店への影響 | 先輩の負担、既存の係・常連への影響 | 要確認 |
| 守れたか | 約束した説明、顔出し不要、保証的表現の有無、個人情報の扱い | 全項目 OK が前提 |

## 2. 判断の3区分
| 判断 | 目安となる状況（案） | 次の行動 |
|---|---|---|
| **継続** | 届いた、自発的な相談がある、負担が許容内、約束を守れた | 体験会をもう1〜2回。別の協力者・別地域を試す。短期滞在の設計を詳細化 |
| **修正** | 一部の観点のみ弱い（例：届くが相談に進まない／相談はあるが負担が大きい） | `02`の「見直し順」で、対象→言葉→届け方→内容→条件説明を1つずつ変えて再試行 |
| **停止／保留** | 反応がほぼない状態が修正後も続く、負担が許容を超える、約束が守れない、本人の納得に問題がある | 投資しない。原因を記録し、再開条件を決める |

- 参加人数が仮目標に届かないことだけで停止しない。入店への近さ（相談・面談の質）も見る。
- 逆に参加が多くても、自発的な相談がない／負担が過大なら「継続」にしない。

## 3. 短期滞在支援（第2段階）へ進む条件（案）
すべて満たすこと：
1. 体験室で、自分の意思で個別相談に進む人が**複数回の開催で**確認できた（件数・開催回数の基準：要確認）。
2. 条件（`04`）の空欄が全て確定し、あやママが承認している。
3. 現場確認の希望者が実際にいる（東京近郊の面談・現場確認で確かめた上で）。
4. 交通・宿泊支援の**対象・予算上限・負担方法**が事前に合意されている（無条件の全員提供にしない）。
5. 滞在中の実際の業務は条件を明示した**有償勤務**とし、模擬接客と区別できる。
6. 窓口担当・指導担当が決まり、特定の一人に実務が集中しない。
7. 法的確認（雇用・募集・宿泊の取扱い）が終わっている［確認先・要確認］。

## 4. 入店後の判断
- 入店者が出たら、`05`シート4で最初の30日の育成を記録。
- 継続評価は**入店後90日**。運用30日／90日の期間とは別。定着結果を早期に確定しない。
- 90日定着者1人当たり費用（途中離脱者の費用を含む）を算出して、投資の妥当性を見る。
